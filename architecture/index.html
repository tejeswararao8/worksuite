DB-->>REPO: result REPO-->>SVC: result AUD->>AUD: async save to audit_logs SVC->>NOTIF: async send notification (if needed) SVC-->>CTL: result CTL-->>C: ApiResponse wrapped JSON MDC->>MDC: log URI + status + duration + traceId MDC->>MDC: MDC.clear() TI->>TI: TenantContext.clear()
